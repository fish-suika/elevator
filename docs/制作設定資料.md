# エレベーター係 — 制作設定資料（本人作成・2026-10-06）

## 決定事項（本人との確認）
- 画面は縦画面専用。PC は 9:16 の枠を中央に表示、スマホは縦持ちでタップ操作（BULLET TIME と同じ）
- Phase を順に進め、各 Phase の終わりに本人が遊んで OK を出してから次へ

---

1. ゲーム概要
短時間で遊べるブラウザゲーム。プレイヤーはホテルなどのエレベーター係となり、乗客から指定された階へエレベーターを動かして案内する。
ゲーム開始時は単純な「指定された階のボタンを押すだけ」のゲームだが、ステージが進むにつれて乗客の注文が複雑になり、徐々に混乱していく。
ゲームの面白さは、操作自体は最後まで簡単なのに、状況だけがどんどんおかしくなっていくこと。

2. 基本コンセプト
「エレベーターのボタンを押すだけなのに、客の注文がどんどん面倒になるゲーム」。1プレイ約5～10分。難しい操作や複雑なルールは避ける。

3. 対応環境
PC/スマホ、ブラウザ、HTML+CSS+JS、3D は Three.js。外部素材ファイル（画像・3Dモデル・音声）は使わない。キャラや家具はプリミティブ形状中心。スマホはタップだけで遊べる。

4. 基本ゲームループ
乗客が乗る → 目的階を伝える → プレイヤーが階数ボタンを押す → エレベーター移動 → 到着 → 降りる → 次の乗客 → 徐々に注文が複雑に → 評価 → リザルト

5. 序盤
非常に簡単。客「3階お願いします」→ ボタン `1 2 3 4 5` → 3 を押す → 3階へ → 客「ありがとうございます」。何人か繰り返してルールを自然に理解させる。

6. エレベーター画面
中央にエレベーター内部（3D）。階数表示・階数ボタン・開閉ボタン・乗客・扉。壁・床・天井・ボタンパネルは BoxGeometry 等で。

7. 階数
B2 B1 1F 2F 3F 4F 5F 6F 7F 8F 9F 10F。序盤は 1～5 階程度、進むにつれて増やす。

8. 乗客システム
簡易 3D キャラ（頭 Sphere、体 Box、腕・脚は細い Box）。乗客ごとに見た目の違いをつけてよい。

9. 難易度上昇（制限時間ではなく注文を面倒にする）
- Lv1「3階お願いします」
- Lv2 到着後「……あ、やっぱり4階です」
- Lv3 複数乗客（A:3階 B:5階 C:2階）を覚えて処理
- Lv4 移動中に変更「すみません！6階にしてください！」
- Lv5 変な注文「4階で一回止まって、そのあと8階」「2階を通過するときに止めて」「5階には行かないで」「10階、でも9階で一度ドアを開けて」。理解不能にはしない

10. バカゲー要素
存在しない階「100階」、「地下10階」、「上に行きたいです」（何階？→「上です」）、「いつものところで」、客同士の会話で目的階が入れ替わる。

11. ミスシステム
即ゲームオーバーにしない。正解 +100、間違い -50、待たせる -10、無茶な注文を処理 ボーナス。

12. 評価
★と S〜C ランク＋一言。称号例：完璧なエレベーター係／普通のエレベーター係／ボタン押し職人／客に振り回された人／エレベーター向いてない／なぜこの仕事を選んだ

13. ゲーム終盤
最後の客「100階お願いします」→ 画面が少し暗くなり 10F→11F→12F→13F… と存在しない階へ → 謎の階に到着 → 扉が開く → 終了。

14. オチ
ホラーにせず「なんだったんだこの仕事」。扉の先は何もない →「本日の勤務終了」→ 本日の評価 ★★★☆☆「よく頑張りました。」

15. 操作
PC：クリック（数字キーも可）。スマホ：タップのみ。移動キー・カメラ操作は不要。

16. UI
上部「現在階：3F」、中央エレベーター内部、下部に階数ボタン、右下に「開く」「閉じる」。

17. 3D 表現
リアルさより分かりやすさ。床・壁・天井・扉・ボタンパネル・ボタン・階数表示・簡易乗客、すべてプリミティブ。

18. カメラ
エレベーター内部を正面から見る固定カメラ。

19. 移動演出
階数表示の変化、上昇・下降音、軽い画面振動、表示が高速で変わる。音なしでも成立させる。

20. 設計方針
操作を難しくするのではなく状況を難しくする。操作は最後まで「正しい階のボタンを押す」。

21. テンポ
最初の1～2分 簡単 → 中盤 少し忙しい → 後半 混乱 → 終盤 完全にバカゲー。

22. 入れないもの
育成・アイテム収集・長時間前提・複雑なストーリー・複雑な操作・大量素材・外部3Dモデル・オンライン機能。

23. 最終体験
「最初はただのエレベーターゲームだったのに、なんで最後こんなことになってるんだよｗ」

24. 実装優先順位
- Phase 1: エレベーター3D空間／階数ボタン／現在階表示／ボタンで階移動／簡単な乗客
- Phase 2: 乗客の目的階／正解判定／スコア／次の乗客
- Phase 3: 難易度上昇／注文変更／複数乗客／特殊な注文
- Phase 4: バカゲー展開／存在しない階／終盤イベント／エンディング
- Phase 5: UI調整／PC・スマホ操作調整／演出追加／バグ修正／テンポ調整
